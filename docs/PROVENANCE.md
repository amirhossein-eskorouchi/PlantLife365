## Provenance rule

The historical archive is the immutable baseline.

Files will be migrated selectively into PlantLife365 only after they are
classified as one of:

- maintained source
- refactored maintained source
- historical/reference implementation
- research extension
- private/archive-only material

No private database, credential, runtime media, or complete raw archive
should enter repository history.
