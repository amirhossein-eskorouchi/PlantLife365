This directory contains repository-safe visual material.

## Current Reviewed Assets

- `.gitkeep`

## Asset Policy

Visual material should be reviewed before inclusion for:

- user information
- private telemetry
- device credentials
- workstation paths
- unrelated copyrighted material
- misleading experimental claims

Private runtime media belongs outside Git.

Historical images should not be copied directly from the private archive without review.
